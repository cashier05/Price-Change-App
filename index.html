Install di iPhone / Safari

Agar aplikasi ini lebih mudah diakses seperti aplikasi native:

1. Ketuk tombol Share (ikon kotak dengan panah ke atas ⎋) di bagian bawah browser Safari.
2. Geser menu ke bawah, lalu pilih "Add to Home Screen" (Tambah ke Layar Utama).
3. Ketuk Add (Tambah) di pojok kanan atas.
